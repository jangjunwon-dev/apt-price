# 🏢 아파트 매매 실거래가 조회기 (Public Data API + Streamlit)

국토교통부 공공데이터 API로 **지역·기간별 아파트 매매 실거래가**를 조회하고,
통계·그래프로 확인한 뒤 **보기 좋게 정리된 엑셀 파일**로 내려받는 웹앱입니다.

## 주요 기능
- 전국 16개 시·도, 256개 시·군·구 선택 (행정안전부 2026.10.26 법정동코드 기준)
- 2006년부터 기간 선택, 한 번에 최대 24개월 조회 (월별 자동 호출·6시간 캐시)
- 해제(취소) 거래 제외, 평형·전용 평당가 자동 계산
- 거래 건수, 평균·중위 거래가, 평균 전용 평당가 요약
- 월별 평균 거래가 추이·월별 거래 건수 그래프, 거래 많은 단지 TOP 10
- 실제 거래된 단지 목록에서 골라 비교하는 단지 선택 필터, 전용면적 필터
- 엑셀 다운로드: 한글 기준 열 너비, 천 단위 쉼표, 제목 행 고정·필터, 빈 열 자동 제거
- 처음 사용자를 위한 홈 화면, 로고를 누르면 처음 화면으로 초기화

## 문제 해결 사례
2026년 7월 전남광주통합특별시 출범으로 광주·전남의 지역 코드(29, 46)가 폐지되고
12로 시작하는 새 코드가 생기면서, 해당 지역 조회 결과가 0건이 되는 문제가 있었습니다.
API 응답 원문을 확인하는 기능을 추가해 원인을 찾았고, 행정안전부 최신 법정동코드로
전체 지역 목록을 갱신해 해결했습니다.

## 사용 기술
Python, Requests, XML 파싱(ElementTree), pandas, openpyxl, Streamlit

## 데이터 출처
공공데이터포털 - 국토교통부_아파트 매매 실거래가 상세 자료 (Open API)
행정안전부 - 행정기관(행정동) 및 관할구역(법정동) 코드

※ 개인정보 보호를 위해 호수는 제공되지 않으며, 동 정보는 등기가 끝난 거래에만 표시됩니다.

## 로컬 실행
```
pip install -r requirements.txt
streamlit run app.py
```
인증키는 코드에 넣지 않고 `.streamlit/secrets.toml`에
`SERVICE_KEY = "발급받은 인증키"` 형태로 저장해 사용합니다. (GitHub에 올리지 않음)
